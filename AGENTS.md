# AGENTS.md

Agent guide for the get release service.

## Repo map

| Path | What |
| --- | --- |
| `src/` | Hono Worker: routes, products, installers, S3/QStash/Neon helpers. |
| `test/` | Vitest suites for products, versions, routes, and integration. |
| `migrations/` | Neon SQL migrations. |
| `scripts/` | Dev, migrate, publish, and build-tool seed helpers. |
| `.depot/workflows/deploy.yml` | Deploy workflow. |
| `wrangler.jsonc` | Worker bindings and the `get.iresolved.link` custom domain. |

## Commands

```bash
just setup          # bun install
just dev            # map .env.get -> .dev.vars and run wrangler dev
just test           # vitest
just typecheck      # tsc --noEmit
just migrate        # apply Neon migrations
just deploy         # wrangler deploy --minify
```

## Product contract

`src/products/` defines every product, channel, platform, artifact kind, and
object-key layout. The public API, update contract, and installers are
documented in `README.md`. Build, Kiln, and build-tool publishers in their own
repositories mirror these definitions.

## Configuration

- `.env.get` is untracked. `GET_*` names map to Worker bindings; `QSTASH_URL`
  and `QSTASH_TOKEN` are CI-only.
- `.dev.vars` is generated by `scripts/dev.ts` and is gitignored.
- Never commit credentials or `.env.get`.
